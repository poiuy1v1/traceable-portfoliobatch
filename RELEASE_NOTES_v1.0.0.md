# Version 1.0.0 release metadata candidate

This candidate contains the frozen retrospective MOFSimplify-derived
activation-stability screening workflow, publication-source-aware evaluation,
raw statistical diagnostics, source data, five stepwise decision traces,
archived-implementation replay checks and exact environment definitions.

The scientific code, data, models, results and traces are unchanged from the
audited predecessor. Version 1.0.0 metadata preparation does not rerun or alter
model selection, the train/calibration/final-evaluation split, policy settings,
reported statistics or scientific claims.

The final author list, author contributions, funding statement and competing-
interests statement have been confirmed. The manuscript states that no relevant
funding was received for this work and that the authors declare no competing
interests.

Both authors have approved MIT licensing for the software release, CC BY 4.0
licensing for the derived-data and figure-source-data release, and public GitHub
plus Zenodo archiving of version 1.0.0.

Public GitHub visibility, immutable tag/release creation and Zenodo archival
registration remain separate service-execution steps. No public release URL or
DOI is claimed until those steps actually succeed.
