# Figure, table and corrected-stability source data

Most CSV files are regenerated by `python scripts/run_full_reproduction.py` and
support Table 1, main Figures 3-5 and Supplementary Figures 1-2. Figure 1 and
Figure 2 are schematic summaries of the implemented protocol and audit outputs.

The corrected secondary policy-stability source data are regenerated by:

```bash
python scripts/recompute_v1_0_2_policy_stability.py --repo-root . --output-root .
```

The authoritative corrected file is
`policy_stability_unique_candidate_subsampling_source.csv`. Derived source data
