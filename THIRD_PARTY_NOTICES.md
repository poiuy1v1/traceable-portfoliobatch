## MOFSimplify dataset

This repository derives activation / solvent-removal and thermal-stability
records from:

Nandy, A. et al. *MOFSimplify: Machine Learning Models with Extracted Stability
Data of Three Thousand Metal-Organic Frameworks*. Zenodo (2021),
https://doi.org/10.5281/zenodo.5736562.

- Resource type: Dataset
- Version: 1.1.0
- Upstream archive: `SciData.zip`
- Upstream MD5 reported by Zenodo: `52c434083c83c3ff81f892951f173875`
- License: Creative Commons Attribution 4.0 International

The current package contains processed and derived tables, not a redistributed
copy of the complete upstream archive. Upstream file identities and relative
paths are recorded in `data/upstream/upstream_manifest.csv`.
