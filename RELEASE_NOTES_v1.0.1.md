# Version 1.0.1

This patch release corrects public-release metadata that remained in a private
staging state in the immutable `v1.0.0` archive.

Only release-facing metadata is changed:

- `README.md` now describes the repository as public and points to the archived
  `v1.0.0` Zenodo DOI;
- `CITATION.cff` uses durable citation wording and version `1.0.1`;
- `VERSION` is updated to `1.0.1`;
- these release notes document the correction.

No scientific code, data, model, result, trace, figure, workflow, statistical
output, split assignment, policy setting or manuscript claim is changed.

The repository is connected to Zenodo. Each published GitHub release is archived
as a versioned software record; use the DOI shown on the corresponding Zenodo
record when citing this release. The immutable `v1.0.0` release and its Zenodo
record remain preserved unchanged.
